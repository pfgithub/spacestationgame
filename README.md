# Orbital

A quiet first-person zero-gravity space station game. Built with Three.js + Vite + TypeScript.

```
npm install
npm run dev      # play at http://localhost:5173
npm run build    # static build into dist/
```

## Controls

| Key | Action |
| --- | --- |
| Mouse | look |
| W | push off (one push = speed 1, keep holding for speed 2, tap repeatedly to go a bit faster) |
| S | grab and stop; keep holding to push backwards |
| Q / E | roll |
| Left click | use |
| Right click | grab / place / let go |
| R | read the paper you are holding |
| T | clip tether to an anchor (spacewalk) |
| Space | reel in tether |
